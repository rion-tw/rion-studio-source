# AI Context Scope

- Keep this directory limited to durable routing context and shared Codex skills.
- Put product semantics in canonical engineering documents and link them instead
  of copying them into context summaries.
- Put reusable validation procedures under `docs/validation/runbooks` and
  immutable task evidence under `docs/validation/archive`.
- Update `.agents/context-map.json` and its focused tests whenever a source area,
  canonical document, risk, validation profile, or E2E feature route changes.
