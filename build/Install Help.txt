Rion Studio macOS installation

1. Drag Rion Studio to the Applications folder.
2. Try to open Rion Studio once.
3. If macOS blocks it, open System Settings > Privacy & Security and click
   Open Anyway for Rion Studio.
4. If Open Anyway is unavailable, open Terminal and run this one-time fallback:

   xattr -dr com.apple.quarantine "/Applications/Rion Studio.app"

5. Open Rion Studio from Applications.

The fallback command removes quarantine only from Rion Studio. It does not
disable Gatekeeper system-wide.

Rion Studio macOS 安裝

1. 將 Rion Studio 拖到 Applications 資料夾。
2. 先嘗試開啟 Rion Studio 一次。
3. 如果 macOS 阻擋執行，請前往「系統設定 > 隱私權與安全性」，在
   Rion Studio 的提示旁按一下「仍要打開」。
4. 如果沒有顯示「仍要打開」，請開啟「終端機」並執行以下一次性備用指令：

   xattr -dr com.apple.quarantine "/Applications/Rion Studio.app"

5. 從 Applications 開啟 Rion Studio。

此備用指令只會移除 Rion Studio 的隔離屬性，不會停用整個系統的 Gatekeeper。
