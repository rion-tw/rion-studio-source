# Documentation Scope

- Write active engineering documentation in English. Localized product and
  legal documents retain their declared locale.
- Treat `docs/README.md` as the active catalog and `.agents/context-map.json` as
  the machine-readable AI routing authority.
- Keep normative behavior in contracts or policies; context files contain only
  summaries and links.
- Files listed in `docs/validation/archive/manifest.json` are immutable evidence.
  Add a new archive record instead of editing an existing artifact.
- Update local links, the catalog, and focused documentation tests with every
  documentation move or split.
